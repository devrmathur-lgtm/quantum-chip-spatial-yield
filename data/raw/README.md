# Raw and cleaned source-data slot

The original project used public QuTech/imec fabrication data and intermediate cleaned tables.

The actual original data files are not available as byte-retrievable artifacts in the current project file store, so they have not been recreated from guesses.

Restore the following historical artifacts here or in the processed-data folder according to `docs/audit/original_artifacts_required.md`:

- imec_step1_clean_map.xlsx
- imec_JV_cleaned_long.csv
- qutech_spatial_characterization_final.xlsx

The public source literature should also be cited in the repository documentation rather than silently redistributing third-party material whose reuse status has not been checked.
