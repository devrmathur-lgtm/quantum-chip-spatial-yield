# Low-sigma q sensitivity

The final project added a q-by-sigma analysis to determine how much residual spatial structure is required for a useful low-spread yield effect.

Recovered selected 10 MHz results:

- q = 0.05: +1.87 percentage points yield advantage
- q = 0.10: +4.09 percentage points
- q = 0.20: +8.45 percentage points
- q = 0.67549: +38.384 percentage points under the original constant-q scale-family result

These values show that practical yield conclusions depend on retained covariance strength.

The complete original q-by-sigma grid and its raw JSON output are not recoverable in the current file store. They are listed in `docs/audit/original_artifacts_required.md`.
