# Primary Dolan spatial-versus-shuffled result

The preregistered primary experiment was run at the measured-data-derived Dolan frequency spread:

\[
\sigma_f = 97.57841384\ \mathrm{MHz}.
\]

The frozen spatial covariance fraction was:

\[
q = 0.67549.
\]

Using 100,000 paired realizations:

- spatial mean collisions = 14.10008
- shuffled mean collisions = 19.12500
- paired delta = -5.02492 collisions
- relative reduction = 26.27%

The paired control preserves the same realized error values and changes only their assignment to processor sites.

This supports the model-level conclusion that spatial organization changes collision statistics at fixed realized error values.
