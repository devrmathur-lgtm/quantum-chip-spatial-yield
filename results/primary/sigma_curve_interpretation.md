# Full sigma-curve interpretation

The original project evaluated a constant-q scale family over:

0, 5, 10, 14, 20, 30, 40, 50, 60, 70, 80, 90, 97.57841384, 100, 110, 120, 132.3, and 150 MHz.

The model keeps q = 0.67549 fixed while scaling total sigma_f.

This sweep is scientifically useful as a covariance-shape-preserving scaling experiment.

It should not be described as a unique physical trajectory from the original fabrication process to a post-tuned low-spread processor.

The archived complete curve rows are not recoverable in the current file store. `sigma_curve_recovery_index.csv` therefore records only exact values that are present in the final project record and leaves the other cells blank rather than inventing data.
